Accessibility Statement

How usable this website is for everyone, what we know still falls short, and how to tell us about a problem.

October 2026
Still to be checked before launch

Taken from the notice published at staging-ai.secondread.co.uk on 13 October 2026. The testing described here was carried out on the live site, not on this prototype. Repeat it against whatever is actually shipped before the statement is published, and date it to that run.

This statement applies to this website. We want as many people as possible to be able to use it: you should be able to zoom in up to 400% without the text spilling off the screen, move around the site using just a keyboard, and use it with a screen reader.

How accessible the site is

We aim to meet the Web Content Accessibility Guidelines (WCAG) 2.1 at level AA. Before launch, every page was checked with automated testing (axe-core) at desktop and phone sizes, and the keyboard focus, menus and forms were checked by hand.

What we know is not fully accessible

  • The downloadable sample report is a PDF. The same report is on the sample report page in an accessible format.
  • Automated testing finds only some accessibility problems. If you find one, please tell us.

Tell us about a problem

If you have difficulty using the website, or need information in a different format, email info@secondopinionradiology.co.uk or call +44 7947 834584. We will reply within 7 working days.
